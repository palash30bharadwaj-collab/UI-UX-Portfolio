Safety, reliability, identity, and book-condition questions can stand between a reader and a request.

06 / DESIGN DECISIONS

Trust first.
Then make it easy.

01

Trust before transaction

Surface lender verification, reputation, borrowing history, and book condition before a borrower commits. The extra context supports confidence in a peer-to-peer exchange.

↗
02

Design for the full borrowing lifecycle

Make the borrowing period, handover, status, and return part of the experience—not an afterthought once a book has changed hands.

↗
03

Make the next step feel clear

Keep the borrower journey legible from nearby discovery to request, while the wider product direction supports reminders, extensions, and return confirmation.
